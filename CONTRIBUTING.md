# Contributing to flutter-to-ios

Thanks for helping make this better for every Flutter developer moving to iOS.

## What to contribute

- **New mappings** — found a Flutter concept missing from the table? Add it.
- **Better examples** — shorter, clearer, more idiomatic code samples.
- **Corrections** — wrong Swift or Dart? Please fix it. Accuracy matters.
- **New sections** — widgets, testing, animations, accessibility.
- **Project examples** — more side-by-side Flutter/SwiftUI mini-apps.

## How to contribute

1. Fork the repo
2. Create a branch: `git checkout -b add/your-mapping`
3. Make your change
4. Open a PR with a clear title: `Add: StaggeredGrid → LazyVGrid mapping`

## Code style

- Dart: follow official Dart style guide
- Swift: follow Swift API Design Guidelines
- Keep examples minimal — show only what's needed to make the point
- Always show both sides (Flutter AND SwiftUI) for any new comparison

## Questions

Open an issue. Happy to discuss before you spend time on a PR.
