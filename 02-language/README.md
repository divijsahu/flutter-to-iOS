# ⚡ Language Basics

Swift and Dart are both modern, type-safe languages with strong inference. Once you see the patterns, you'll feel at home within a day.

| File | Topic |
|---|---|
| [variables.md](variables.md) | `var` vs `let`, type inference, string interpolation |
| [functions.md](functions.md) | Parameter labels, default values, closures |
| [optionals.md](optionals.md) | Swift's null safety — `if let`, `guard let`, `??` |
| [collections.md](collections.md) | Arrays, dictionaries, sets, higher-order functions |
| [error-handling.md](error-handling.md) | `throws`, `do/try/catch` vs Dart exceptions |
| [enums.md](enums.md) | Swift's powerful enums with associated values |

> **Key insight:** Dart has `var` / `final` / `const`. Swift has `var` / `let`. That's it. `let` in Swift covers both `final` and `const` depending on context.
